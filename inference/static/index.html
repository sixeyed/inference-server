Request parameters

      

        Clients send their own sampling settings, which override whatever the
        model's file in models/ tuned it
        to. Strip one here and the model's own default applies instead. Takes
        effect on the next request — no restart — and is remembered
        across restarts.
      

      

      

    


    

      
System prompt

      

        Clients send their own system prompt — VS Code's runs to about
        15,000 characters of Copilot framing. Substitute named blocks of it per
        client from the prompts shipped in
        inference/prompts/. Blocks you
        don't name pass through untouched, and only the first match of
        a tag is replaced, so VS Code's second
        <instructions> block —
        the one carrying workspace skills and agents — survives.
      

      

        The same clients send their whole tool surface every turn — VS Code
        sends about 23,000 tokens of JSON schema, and the traces here show it
        calling 18 of 103 tools. A tool set from
        inference/toolsets/ names the ones
        it may offer. A set that matches nothing is treated as a typo and
        ignored: zero tools doesn't fail a coding agent, it quietly stops it
        being one.
      

      

        A model that gets stuck re-issuing one tool call cannot sample its way
        out — the repetition is across turns, not within a generation, so
        temperature and penalties never see it. Set a trigger count and the
        engine replaces a run of byte-identical calls with a note carrying what
        came back, never the arguments that produced it. A real poll whose
        output changes is never a match; set 0
        for one whose output doesn't.
      

      

    

  


  

    

      
Clients

      

        Point a coding client at any of these addresses and pick a model; the
        first request for a model starts it. The API key is
        none. For VS Code, paste the block
        into your user settings.json as the
        value of github.copilot.chat.customModels.
      

      

    

  


  

    

      
Logs

      

        What the engine changed about a request, and when. Recorded when
        something changes rather than on every turn, so a long session
        with steady settings writes nothing. A
        drift
        line is the one to act on: the tool set names a tool the client has
        stopped offering, which is what a rename in a client release looks like
        — the model has silently lost that tool.
